Workflow

Load data→Clean (rule-based)→ Separate X and y→Train / test split→ Fit imputer + scaler + encoder on TRAIN→Transform train & test→ Train models→Save pipeline
No data leakage: the split happens before any statistic is learned. Medians, means, standard deviations and category lists are computed on the {{ p.train_size|num }} training rows only; the {{ p.test_size|num }} test rows are only transformed. Only the first encounter of each patient is kept so the same patient can never appear in both sets.
